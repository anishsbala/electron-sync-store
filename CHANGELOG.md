# Changelog

All notable changes to this project are documented here.

## 0.1.0 - 2026-09-01

- Added typed shallow stores and runtime serializability validation.
- Added canonical main-process state, revisions, epochs, deduplication, no-op
  acknowledgments, and mutation rejection.
- Added context-isolated Electron transport and optimistic renderer replicas.
- Added pending-aware recovery, same-ID retry, bounded queues, and `flush()`.
- Added concurrent-safe React selector and synchronization hooks.
- Added the Controller, Observer, and Inspector Electron demo.
- Added unit, integration, smoke, E2E, and package-consumer verification.
